# Support

Use the studio support form:

- English: https://wowd0t.github.io/Onyx_Meridian_project/en/support.html
- Russian: https://wowd0t.github.io/Onyx_Meridian_project/ru/support.html

Choose **Add-on**, then **Gloamguise: False Facades**, then the request category: bug report, improvement, suggestion, question, permission request or licence question.

For permission requests, include the Work, version, requested action, scope, platforms, duration, commercial terms, file changes and credit plan. The rights holder replies with permission granted, permission granted with conditions, or denial. Silence is not approval.
