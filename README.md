# Gloamguise: False Facades

**English**

Gloamguise: False Facades is a Minecraft Bedrock add-on by Onyx Meridian Interactive Studio about building secret bases that survive close inspection. It adds ten camouflage items: pass-through ghost walls, one-way spy glass, camouflaged doors and trapdoors with independent halves, and torch-shaped levers that can open a vault from another room without a redstone signal.

The add-on is designed around a vanilla-first aesthetic: copied faces, log direction, grass tint and block states are rebuilt so a decoy blends into the surrounding build. It is a system for hidden entrances, observation points, flush hatches and remote switches, not a one-off texture swap.

## Официальный русский перевод

Gloamguise: False Facades — аддон для Minecraft Bedrock от Onyx Meridian Interactive Studio о строительстве секретных баз, которые выдерживают внимательный осмотр. Он добавляет десять маскировочных предметов: проходимые призрачные стены, одностороннее смотровое стекло, маскировочные двери и люки с независимыми половинками и факелы-рычаги, способные открыть хранилище из другой комнаты без сигнала редстоуна.

Аддон построен вокруг ванильной эстетики: скопированные грани, направление брёвен, оттенок травы и состояния блока восстанавливаются так, чтобы маскировка сливалась с окружающей постройкой. Это система для скрытых входов, наблюдательных точек, люков вровень с полом и дистанционных переключателей, а не одноразовая замена текстур.
